---
title: BBCode post formatting
---

Tormater Forum supports all the standard BBCode tags, and a few more.<br>
Here's a list of all the tags that are supported:<br>
***
| Tag | Effect   | Example         |
|-----|----------|-----------------|
| `[b]` | **Bold** | `[b] Content [/b]`  |
| `[i]` | *Italic* | `[i] Content [/i]`  |
| `[s]` | ~~Strike~~ | `[s] Content [/s]`  |
| `[u]` | <u>Underline</u> | `[u] Content [/u]`  |
| `[url]` | [Link]() | `[url=www.example.com] Content [/url]`  |
| `[img]` | Image | `[img] www.example.com/example.png [/img]`  |
| `[spoiler]` | <details><summary>Spoiler</summary>Content</details> | `[spoiler=Title] Content [/url]`  |
| `[code]` | `Code` | `[code] Content [/code]`  |
| `[color]` | Color | `[color=#000000] Content [/code]`  |
| `[size]` | Size | `[size=20] Content [/size]`  |
| `[h]` | <u><b>Heading</b></u> | `[h] Content [/h]`  |
| `[h2]` | <u><b>Sub-Heading</b></u> | `[h2] Content [/h2]`  |
