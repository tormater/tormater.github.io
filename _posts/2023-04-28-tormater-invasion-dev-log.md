Today, I've modified the wall tower type to have 3 new upgrades, with higher strength and durability. They can be upgraded in the intermission screen, much like towers. I've also added colored lights, which display on a new layer, so that they stay vibrant.

![]({{ "assets/images/news/screenshot_3.png" | absolute_url }})
<br><small>The intermission screen, with the upgrade options for turrets and walls.</small>

For the first "world" of Tormater Invasion, I've added two boss fights, in level 8, and a final one in world 16. Levels end when the player has killed the required amount of enemies (for level 1, it's 30, and level 2, it's 60, and so on), so I interrupt the level ending process, and spawn the boss, which for now assumes the appearance of a giant TorMantle.

Once the boss is killed, the level is ended. If you use the level select menu to pick an already-played level, you cannot move on to the next level, and a boss will not spawn either.
